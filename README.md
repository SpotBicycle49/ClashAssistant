# Clash Assistant — версия 0.1.0

Анализ записей матчей Clash Royale после игры: разметка карт соперника, цикл колоды,
расчётный эликсир с диапазоном неопределённости, история матчей.

## Что работает и что нет

| Функция | Статус |
|---|---|
| Импорт видео, покадровый просмотр, шаг ±0,2 / ±1 с | работает |
| Отметка «бой начался здесь» (синхронизация видео и таймера боя) | работает |
| Ручная отметка карт соперника, исправление, удаление | работает |
| Движок эликсира: старт 5, максимум 10, ×1 / ×2 / ×3, интервал мин–макс, Зеркало | работает, покрыт тестами |
| Поиск противоречий («эликсира не могло хватить») | работает |
| Колода и цикл: какие карты в руке, какая следующая | работает, покрыт тестами |
| История матчей (Room, на телефоне) | работает |
| Настройки правил эликсира | работает |
| **Автоматическое распознавание карт** | **не реализовано** — нужен образец записи |
| Сборщик эликсира, режимы 2×2 и особые | не реализовано |

## Структура

```
app/src/main/java/com/clashassistant/
  MainActivity.kt            — запуск и нижнее меню из 6 разделов
  MatchViewModel.kt          — связывает видео, движки и базу
  model/Models.kt            — Card, PlayEvent, CardCandidate
  data/cards/CardCatalog.kt  — база карт (название + стоимость), правится вручную
  data/db/Database.kt        — Room: матчи и события
  data/prefs/RulesStore.kt   — настройки правил эликсира
  engine/elixir/             — математика эликсира (без Android, тестируется)
  engine/deck/DeckTracker.kt — колода и цикл
  vision/video/VideoFrameSource.kt — извлечение кадров (экономно по памяти)
  ui/                        — тема, графики, экраны
app/src/test/                — unit-тесты движков
.github/workflows/build.yml  — автоматическая сборка APK на GitHub
```

## Как получить APK — вариант 1: GitHub (ничего не устанавливать)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **New repository**, назовите `ClashAssistant`, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите
   **содержимое** распакованной папки `ClashAssistant` (не саму папку).
   Папка `.github` скрытая: в Windows включите «Показывать скрытые файлы»,
   иначе сборка не запустится.
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions** и дождитесь зелёной галочки (5–10 минут).
6. Откройте запуск, внизу в **Artifacts** скачайте `ClashAssistant-apk`, распакуйте ZIP.
7. Скопируйте `app-debug.apk` на телефон и откройте его. Разрешите установку из этого источника.

Если галочка красная, откройте запуск и пришлите текст ошибки.

## Вариант 2: Android Studio

1. Установите Android Studio: https://developer.android.com/studio (на ПК нужно 8 ГБ RAM).
2. **File → Open** → папка `ClashAssistant`. Дождитесь окончания синхронизации Gradle.
3. Тесты: правой кнопкой по `app/src/test` → **Run Tests**.
4. APK: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
   Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Как пользоваться

1. Запишите повтор или бой стандартной записью экрана Android.
2. **Анализ → Выбрать видео.**
3. Найдите момент, когда таймер показывает 3:00, нажмите **«Бой начался здесь»**.
4. Перематывайте; когда соперник играет карту — **«Соперник сыграл карту…»** и выберите её.
5. Смотрите **Эликсир** и **Колода**, сохраните матч.
