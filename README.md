# Clash Assistant — версия 0.2.0

Разбор повторов Clash Royale после игры: приложение само находит розыгрыши соперника,
их стоимость и карты, восстанавливает колоду и цикл, показывает фактический и расчётный эликсир.

## Что работает и что нет

| Функция | Статус |
|---|---|
| **Автораспознавание повторов**: все розыгрыши соперника, стоимость, карта, начало боя | работает, проверено на реальном повторе (21/21) |
| Фактический эликсир соперника из повтора + точность расчёта | работает |
| Подпись карт соперника один раз, дальше — автоматически (библиотека образцов) | работает |
| Движок эликсира: интервал мин–макс, ×1/×2/×3, Зеркало, стоимость из повтора | работает, покрыт тестами |
| Колода и цикл: какие карты в руке, какая следующая | работает, покрыт тестами |
| Ручная разметка и исправление любых событий | работает |
| История матчей (Room, на телефоне), миграция данных с 0.1 | работает |
| Записи своих боёв (рука соперника не видна) | только ручная разметка |
| Сборщик эликсира, режимы 2×2 | не реализовано |

## Как устроено распознавание

Работает с **повтором из журнала боёв**, где сверху видна рука соперника:

1. **Розыгрыш** = резкое падение эликсира соперника на полоске сверху. Величина падения
   (с поправкой на восстановление) и есть стоимость карты — даже для Зеркала и «золотых» карт.
2. **Карта «След.»** меняется при каждом розыгрыше. Её картинки группируются: одна карта колоды —
   одна группа (у карты с эволюцией их две — обычная и эволюционная).
3. **Какая карта сыграна**: по правилам цикла сыгранная карта снова появляется в «След.»
   ровно через 3 розыгрыша. Последние 3 розыгрыша матча определяются по составу руки и стоимости.
4. **Начало боя**: панель повтора появляется через ~2,86 с после 3:00.

Разметка экрана замерена на записи 720×1576 и масштабируется по ширине видео.

```
  vision/video/VideoFrameSource.kt — кадр для просмотра (экономно по памяти)
  vision/replay/ReplayDetector.kt  — распознавание розыгрышей (чистый Kotlin, тест на реальном повторе)
  vision/replay/FeatureExtractor.kt — признаки кадра: панель, эликсир, карта «След.»
  vision/replay/ReplayAnalyzer.kt  — разбор видео пачками кадров + миниатюры карт

```

## Как получить APK — вариант 1: GitHub (ничего не устанавливать)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите **New repository**, назовите `ClashAssistant`, нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите
   **содержимое** распакованной папки `ClashAssistant` (не саму папку).
   Папка `.github` скрытая: в Windows включите «Показывать скрытые файлы»,
   иначе сборка не запустится.
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions** и дождитесь зелёной галочки (5–10 минут).
6. Откройте запуск, внизу в **Artifacts** скачайте `ClashAssistant-apk`, распакуйте ZIP.
7. Скопируйте `app-debug.apk` на телефон и откройте его. Разрешите установку из этого источника.

Если галочка красная, откройте запуск и пришлите текст ошибки.

## Вариант 2: Android Studio

1. Установите Android Studio: https://developer.android.com/studio (на ПК нужно 8 ГБ RAM).
2. **File → Open** → папка `ClashAssistant`. Дождитесь окончания синхронизации Gradle.
3. Тесты: правой кнопкой по `app/src/test` → **Run Tests**.
4. APK: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
   Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Как пользоваться

1. В игре откройте **журнал боёв → повтор** нужного боя и запишите его стандартной записью экрана.
2. **Анализ → Выбрать видео → «Распознать автоматически»**. Разбор занимает 1–3 минуты.
3. **Колода**: подпишите карты соперника (один раз — дальше они узнаются сами).
4. **Эликсир**: график расчёта и факта из повтора, точность расчёта.
5. Ошибки можно исправить карандашом у события. Сохраните матч.
